# 按主线看：世界是怎么运作的

学科是按人类分工切的，主线是按世界本身切的。同一个机制会在不同学科里反复出现，这一页的作用是把它揪出来——你在初中物理见过的「守恒」，和大学热力学的「熵」、编程里的「不可逆操作」，是同一件事的三件衣服。

共 8 条主线。
